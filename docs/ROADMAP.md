## 一、播放体验

| 状态 | 优先级 | 功能 | 备注 |
| :--: | :----: | ---- | ---- |
| ✅ | 🔥 | 音频可视化频谱 | FFT + 频谱柱状，进度条上方融合显示，60 FPS 平滑动画 |
| ✅ | ⭐ | 睡前定时器（Sleep Timer） | 定时停止 + 渐弱音量；支持 10~90 分钟预设，可延时 |
| ✅ | 💡 | 变速变调（Tempo / Pitch） | 0.5x~2.0x 播放速度，播客/学习场景；预设 + 滑块精细调节 |
| ☐ | 🔥 | EQ 均衡器 / 音效预设 | Pop/Rock/Classical/Bass Boost；10 段图形 EQ |
| ☐ | ⭐ | 淡入淡出 / 跨曲混音（Crossfade） | 切歌时音量曲线交叉 |
| ☐ | ⭐ | 无缝接续（Gapless Playback） | 预解码下一首，消除空白 |
| ✅ | 💡 | A-B 复读 | 选段循环，扒谱/学语言；点击设 A/B 点，进度条高亮区间，到 B 点自动跳回 A 点 |

## 推荐落地顺序

1. ✅ **音频可视化频谱**（视觉效果立竿见影）
2. ✅ **播放页视觉风格**（模糊背景 / 黑胶唱片 / 粒子）
3. ✅ **本地 Web 遥控端**（多设备体验质变）
4. ✅ **WebDAV 音乐源**（云端音乐无缝播放）
5. ✅ **睡前定时器**（定时停止 + 渐弱）
6. ✅ **变速播放**（播客/学习场景）
7. ✅ **A-B 复读**（扒谱/学语言利器）
8. ✅ **歌词编辑器**（手动打轴 LRC）
9. ✅ **听歌报告**（Wrapped 风格分享图）
10. **收藏 / 评分 + 智能歌单**（用上现有 play_stats）
11. **逐字卡拉OK 歌词**（QQ 已经有 QRC 数据）
12. **EQ 均衡器**（用户感知明显）
